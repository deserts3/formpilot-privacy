# Política de Privacidade – FormPilot

Última atualização: 31 de outubro de 2026

Esta Política de Privacidade descreve como a extensão FormPilot para Google Chrome ("a Extensão") trata as informações dos usuários.

## Coleta de dados

O FormPilot não coleta, armazena, transmite, vende nem compartilha nenhum dado pessoal ou informação de uso dos seus usuários. A Extensão não envia dados para servidores próprios nem de terceiros.

## Uso de dados

Como nenhum dado é coletado, nenhum dado é usado para publicidade, análise, perfil de usuário, avaliação de crédito ou qualquer outra finalidade. O uso de informações pela Extensão está em conformidade com a Política de Dados do Usuário da Chrome Web Store, incluindo os requisitos de Uso Limitado.

## Serviços de terceiros

A Extensão não utiliza serviços de análise, publicidade ou rastreamento de terceiros.

## Alterações nesta política

Se esta política for alterada, a nova versão será publicada nesta página com a data de atualização revisada.

## Contato

Dúvidas sobre esta política podem ser enviadas pela página de Issues deste projeto: https://github.com/deserts3/formpilot-privacy/issues

# Privacy Policy – FormPilot

Last updated: October 31, 2026

The FormPilot Chrome extension does not collect, store, transmit, sell or share any personal data or usage information. No data is sent to the developer's servers or to any third party. The extension does not use third-party analytics, advertising or tracking services. Its handling of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Questions: https://github.com/deserts3/formpilot-privacy/issues
